# Player Independent Events

### People Interested: Acro

### Description:
Genesis asserts that all events should require the player to be present to occur

Dataplanets would like to create the options for events to occur when the player isn't present

- Intelligent species have conflicts/Events on planets and stations
- A planet may be destroyed or created
- Radios can transmit world/lore information 
- Events can occur anywhere in the universe that might eventually have consequences
