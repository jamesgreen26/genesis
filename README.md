# Genesis
One of the space mods of all time. A Submission to CurseForge's Future Mod Jam

## Ok so...why?
Genesis is a space mod focused on modularity and depth. 
A lot of space mods tend to be "build rocket go to planet, build another rocket, go to another planet"
Whilst Genesis has that, it focuses mainly on more indepth experiences beyond that, that is, infinite planets, quests, and atmosphere

One could probably more closely liken this mod to the game `No Man's Sky` - this is not a `No Man's Sky` mod however.

## Let's talk about modules
Whilst this mod functions coherently as one (for the sake of integration its in one jar) it is actually composed of three main modules:
- Genesis the "space engine"
- Dataplanets for celestial bodies and story
- Radios for interwoven communication
